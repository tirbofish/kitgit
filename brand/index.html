01 — mark

Wordmark, not a logo lockup.

Always lowercase. Always monospace. The mark is a solid ink square — no SVG, no lockup. UI chrome elsewhere uses Nerd Font glyphs (nf-md-git, branch, commit, etc.).

One face. Nerd Font first.

Primary stack: JetBrainsMono Nerd Font → JetBrains Mono → FiraCode Nerd Font → system mono. No second family. Hierarchy is weight and size only.

04 — voice

Short. Literal. Quiet.

Name
kitgit — kit + git. A kit you host.
Tagline
Self-hosted git. Templates, not a product page.
Say
“repos”, “bare”, “clone url”, “owner”, “push”. Prefer verbs over marketing nouns.
Don’t say
“forge platform”, “developer experience”, “seamless”, “powerful”, “next-gen”.
UI copy
Sentence case. No exclamation marks. Empty states are one line: no repos yet.
Iconography
Nerd Font codepoints only. No SVG icon packs. Prefer text labels when a glyph would be decorative.
